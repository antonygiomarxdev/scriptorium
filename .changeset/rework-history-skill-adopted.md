`scriptorium rework history` rebuilds every finding of the rework queue from git and prints it per week, change and cause. The `/scriptorium:rework` skill turns the heaviest cause into a request for the owner. The adopt skill says where a verbatim export of another tool goes (archive/<tool>/ at the repo root, linked on a Source line). approve and clear find the project from the document path, so they work from any folder. A fixture of an adopted project is checked in the tests.
