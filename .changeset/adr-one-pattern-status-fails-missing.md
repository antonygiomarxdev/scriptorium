Format 5. An approved TP that cites an ADR finds the ADR by the same file rule the tp check uses, so four-digit and legacy NNNN-name.md ADRs are found and a longer number is not mistaken for a shorter one. A cited ADR with no file fails the status check; a project pinned below format 5 gets a warning instead. Run migrate to move the pin.
